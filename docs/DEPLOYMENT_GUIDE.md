## 1. Quick Deploy via Render Blueprint (Recommended)

The repository includes a ready-to-use [`render.yaml`](../render.yaml) blueprint specification that configures the build, startup, health checks, and environment variables automatically.

### Step-by-Step Instructions:
1. **Log in to Render:** Navigate to [dashboard.render.com](https://dashboard.render.com).
2. **Create New Blueprint:**
   - Click **New +** in the top right corner.
   - Select **Blueprint**.
3. **Connect Repository:**
   - Select your GitHub account and choose `AI-Customer-Support-Agent-with-Persistent-Memory`.
   - Click **Connect**.
4. **Configure Secrets:**
   Render will inspect `render.yaml` and prompt you for the uncommitted secret keys:
   - `HINDSIGHT_API_KEY`: Enter your Vectorize Hindsight API key (`hs_...`).
   - `GROQ_API_KEY`: Enter your Groq Cloud API key (`gsk_...`).
   *(Note: `SESSION_SECRET` is automatically generated by Render using a cryptographically secure 256-bit random string).*
5. **Apply & Deploy:**
   - Click **Apply**.
   - Render will trigger the build pipeline:
     1. Installs Python 3.12.3 dependencies from `requirements.txt`.
     2. Runs `python scripts/seed_demo.py --local-only` to seed Priya, Arjun, and Meera into SQLite.
     3. Starts Uvicorn listening on `0.0.0.0:$PORT`.
     4. Runs health checks against `/api/health`.
6. **Access Public URL:**
   Once the status turns **Live**, Render assigns your public URL (e.g. `https://paynest-support-agent.onrender.com`).

## 2. Alternative: Manual Web Service Setup

If you prefer manual setup without Blueprint:

1. In Render Dashboard, click **New +** > **Web Service**.
2. Connect `https://github.com/VamshiYamjala/AI-Customer-Support-Agent-with-Persistent-Memory`.
3. Set the configuration:
   - **Name:** `paynest-support-agent`
   - **Region:** Any (e.g. Oregon, Frankfurt, Singapore)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt && python scripts/seed_demo.py --local-only`
   - **Start Command:** `uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT`
   - **Plan:** `Free`
4. Expand **Advanced** and set:
   - **Health Check Path:** `/api/health`
5. Under **Environment Variables**, add:
   | Key | Value | Notes |
   |---|---|---|
   | `PYTHON_VERSION` | `3.12.3` | Matches local development |
   | `APP_ENV` | `production` | Enables production mode |
   | `HINDSIGHT_BASE_URL` | `https://api.hindsight.vectorize.io` | Hindsight Cloud |
   | `HINDSIGHT_API_KEY` | *(Your Hindsight Key)* | Keep private |
   | `GROQ_API_KEY` | *(Your Groq Key)* | Keep private |
   | `GROQ_MODEL` | `openai/gpt-oss-20b` | Production LLM |
   | `SESSION_SECRET` | *(64-character random string)* | Token signing |
   | `DATABASE_URL` | `sqlite:///data/app.db` | Local SQLite path |
   | `ALLOWED_ORIGINS` | `*` | Permits cross-origin web requests |

## 3. Post-Deployment Verification Checklist

Once your Render service is deployed and has a public URL (e.g. `https://<your-app>.onrender.com`), verify the deployment:

1. **Verify Shallow Health:**
   ```bash
   curl https://<your-app>.onrender.com/api/health
   # Expected: {"status":"ok","env":"production","hindsight":"unchecked","llm":"unchecked"}
   ```

2. **Verify Deep Health (Live Cloud Connections):**
   ```bash
   curl https://<your-app>.onrender.com/api/health/deep
   # Expected: {"status":"ok","hindsight":"ok","llm":"ok"}
   ```

3. **Verify Web UI:**
   - Open `https://<your-app>.onrender.com` in your browser.
   - Confirm customer persona is Priya Sharma.
   - Click **`[⚡ Priya Session 2 (Card 4242)]`** to test persistent memory recall.
   - Click **`[⚖️ Compare ON vs OFF]`** to view side-by-side comparison in the chat stream.
   - Click **`[🔒 Arjun Isolation Check]`** to confirm zero data leakage.
   - Submit feedback using **`[✓ That worked]`**.

## 4. Database Persistence Notes

- On Render's **Free Tier**, the filesystem is ephemeral (it resets whenever the service spins down or restarts). The build command `python scripts/seed_demo.py --local-only` ensures that every restart has a fresh, fully-seeded demo database ready for judges.
- For **Persistent Production Storage**, Render provides persistent disks ($0.25/GB/month on paid instances):
  - Disk Mount Path: `/var/data`
  - Update `DATABASE_URL` to `sqlite:////var/data/app.db`
